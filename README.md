**# AutoOrganizer**

A simple Python project I made to practice programming.

**## What it does**

- Checks if a file is an image or a document.
- Recognizes `.png`, `.jpg`, `.pdf` and `.txt` files.
- Shows where each file should go.

**## How to run**

Make sure Python is installed, then run:

```bash
python main.py
```

**## What I'm learning**

I'm using this project to practice Python, conditionals, string methods and importing modules.

More features may be added as I learn more about Python.
